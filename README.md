# Rupal Photo Studio

Traditional photography by Rajesh Aire, with over three decades dedicated to the craft. He established Rupal Photo Studio in 2006 in Chakala, Andheri East, Mumbai.

**Website:** https://kartikmore04.github.io/

The website uses the studio’s supplied camera symbol and wordmark and includes the complete Ashwin & Chetna album (37 layouts), Rahul & Kirti album (40 layouts), a photograph gallery, studio services, Google Map and direct phone contact.

## Publishing

The finished static website is stored in `site-core.zip` and six `site-albums-*.zip` archives to keep individual browser uploads small. The GitHub Pages workflow assembles all archives, checks both album layout counts and publishes the complete website.

To publish an updated export, replace the relevant archives on the `main` branch. Deployment runs automatically. GitHub Pages uses the GitHub Actions publishing source.

The static contact experience uses the studio phone number; it does not require a database.
